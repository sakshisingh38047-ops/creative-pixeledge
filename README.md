# PhotoPro Studio

Build a complete Flutter Photo Editor App called "PhotoPro Editor" with ALL these features:

BASIC EDITING: Crop, Rotate, Flip, Resize, Brightness, Contrast, Exposure, Saturation, Temperature, Tint, Highlights, Shadows, Blur, Sharpen, Vignette with real-time sliders.

FILTERS & EFFECTS: 50+ Instagram style filters using LUTs, Presets, Frames, Light leaks, Blur effects, Grain, Glitch, Vintage, Cinematic.

CREATIVE TOOLS: Add Text with 20+ fonts, Stickers, Emojis, Drawing/Brush with color and size control, Shapes, Borders, Collage maker with 20 layouts.

PROFESSIONAL TOOLS: Layers system with drag & drop reordering, Masks, Blend Modes (Multiply, Overlay, Screen), Curves, HSL color adjustment, Selective Editing, Perspective Correction, Healing/Clone brush, Noise Reduction, Non-destructive editing with full history and Undo/Redo.

AI FEATURES: AI Background Remover button, AI Background Replacement, Object Removal (inpainting), AI Image Enhancement, AI Upscaling 2x/4x, AI Relighting, AI Effects, Generative Expand.

PROFESSIONAL UI: Modern dark/light mode home screen, Photo picker from gallery, Full-screen editor, Bottom editing toolbar like Lightroom, Right side Layer panel, Before/After button with long press, Save projects, Presets manager, Touch gestures, Pinch-to-zoom, High-resolution preview.

EXPORT: Export as JPG, PNG, WebP, Adjustable quality slider 1-100, Multiple resolutions (Original, HD, Full HD, 4K), Original-resolution export, Save to gallery, Share to Instagram/WhatsApp.

Use pro_image_editor package for base, make UI super modern like PicsArt and Lightroom. Make it fully functional with Flutter web preview.

Build it as a web app first so I can preview instantly.
